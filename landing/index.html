Fitur Utama

Dirancang untuk memenuhi kebutuhan operasional peminjaman ruangan di lingkungan kampus UGM.

🔐

Autentikasi SSO UGM

Masuk menggunakan akun institusi UGM. Setiap peran mendapatkan hak akses yang sesuai.

🏢

Manajemen Ruangan

Kelola data ruangan, kapasitas, lokasi, fasilitas, dan status ketersediaan secara real-time.

📝

Booking Online

Ajukan peminjaman dengan formulir lengkap, termasuk upload surat permohonan PDF hingga 5 MB.

⚡

Deteksi Konflik Otomatis

Sistem memeriksa tabrakan jadwal saat pengajuan dan menampilkan alternatif jika ruangan penuh.

✅

Approval Workflow

Approver dapat menyetujui, menolak, atau meminta revisi dengan alasan yang tercatat.

📧

Notifikasi Email

Pemohon dan approver mendapat pemberitahuan setiap kali status booking berubah.

📊

Dashboard Admin

Pantau jadwal, statistik penggunaan ruangan, dan kelola pengguna dari satu dashboard.

📜

Audit Log

Setiap aksi tercatat rinci: siapa, kapan, perubahan nilai lama & nilai baru.

Alur Peminjaman

Proses yang sederhana, transparan, dan dapat dipertanggungjawabkan.

1

Login SSO

Masuk menggunakan akun UGM. Sistem mengenali peran sebagai user, approver, atau admin.

2

Cari Ruangan

Filter berdasarkan kapasitas, lokasi, fasilitas, dan slot waktu yang tersedia.

3

Ajukan Booking

Isi formulir dan upload surat permohonan. Sistem otomatis mendeteksi konflik jadwal.

4

Approval

Approver meninjau detail booking dan memutuskan menyetujui atau menolak beserta alasannya.

5

Penggunaan & Riwayat

Setelah disetujui, ruangan dapat digunakan. Status & riwayat tersimpan dalam audit log.

Peran Pengguna

Sistem membedakan hak akses berdasarkan peran untuk menjaga keamanan dan kewenangan.

User / Pemohon

Mencari ruangan, mengajukan booking, membatalkan booking, serta melihat status & riwayat peminjaman.

Approver

Meninjau permohonan, menyetujui/menolak booking, dan melihat ringkasan konflik & rekomendasi.

Admin

Mengelola ruangan & fasilitas, menandai maintenance, melihat dashboard, dan memantau audit log.

Deploy & Integrasi

Dibangun untuk dapat di-deploy dengan mudah oleh tim menggunakan Docker Compose dan CI/CD.

Docker Compose

Salin file dan jalankan docker compose up -d --build. Aplikasi berjalan di port 8085.

Cloudflare Tunnel

Akses SSH dan publik ke server dilindungi Cloudflare Access. Tidak perlu membuka port SSH ke internet.

GitHub Actions

Push ke main otomatis membangun image dan mendeploy ke server via tunnel.
